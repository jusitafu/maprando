# MapRando 🗺️

**MapRando** est la nouvelle génération de plateforme cartographique et d'analyse GPX pour randonneurs.
Créé sur les bases solides et éprouvées de RandoFinder (v92), MapRando introduit de nouvelles variations cartographiques, ergonomiques et d'analyse.

## 🚀 Fonctionnalités embarquées :
- **Cartes IGN Officielles** : TOP 25 (Scan 25®), Plan IGN, Vue Aérienne HD.
- **Grille Nationale TOP 25** : Délimitations des 1 861 feuilles papier avec épaisseur adaptative.
- **Étalonnage Écran « 1 cm vrai »** : Choix par Marque et Modèle des 10 dernières années (Apple, HP, Lenovo, Dell, Asus, Acer, Moniteurs).
- **Index IBP Officiel** : Calcul automatique de l'effort physique avec code couleur officiel de 1 à 5.
- **Fiches Randonnées & Profil Altimétrique** : Export PDF haute fidélité avec carroyage UTM kilométrique.
